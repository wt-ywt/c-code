# 学生日程 · 微信小程序

把「课表」和「作业/考试待办」放在同一个应用里，解决课表工具不管 deadline 的问题。

## 功能

- **课程表**：7 天 × 8 节的周视图，课程按节次绝对定位渲染，支持 20 周切换、单双周、连堂课
- **本机存储**：课表和待办都存 `wx.setStorageSync`，不依赖服务器，不需要备案
- **日程待办**：按截止日期排序，自动算「还剩 N 天」，逾期标红
- **上课提醒**：两级——小程序内「下一节课」倒计时，以及课前推到微信的订阅消息
- **添加/编辑课程**：选星期、起始节、连上几节、周次范围、颜色，实时预览

## 跑起来

1. 下载[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）
2. 「导入项目」→ 选中本目录
3. AppID 填自己的（或点「测试号」）。游客模式 `touristappid` 不能真机预览
4. 打开 `config.js`，把 `termStart` 改成你学期第一周的**周一**（不是周一会让整张表错位一天）
5. 编译，点右下角 `+` 加第一门课

## 数据格式

一门课就是一条记录，存在 `courses` 这个 storage key 下：

```js
{
  id: 'c1',
  name: '高等数学',
  teacher: '张老师',
  room: '教3-201',
  day: 1,                          // 1=周一 … 7=周日
  start: 1,                        // 第几节开始
  span: 2,                         // 连上几节
  weeks: [1, 2, 3, 4, 5, 6, 7, 8], // 具体哪几周上
  color: '#4a7cff'
}
```

待办存在 `todos` 下：`{ id, title, date: 'YYYY-MM-DD', done }`。

## 上课提醒

### 第一级：小程序内倒计时（零配置，直接可用）

课表页顶部有一行「下一节 高等数学 · 10/30 周五 08:00 · 教3-201 · 12 小时 46 分后」，
30 秒刷新一次，30 分钟内变红。

这一级不需要任何配置，靠 `utils/remind.js` 的 `nextClass()` 纯前端算出来。
注意它**只有打开小程序才看得见**，不是推送。

### 第二级：微信「服务通知」推送（需配置云开发）

小程序没有本地定时通知能力，想在课前主动弹消息，只有订阅消息这一条路，
而订阅消息必须由服务端在指定时刻调用接口发送，所以需要云函数兜底。

按顺序做这 7 步：

**1. 开通云开发**

开发者工具点顶部「云开发」→ 开通 → 复制环境 ID（形如 `cloud1-9g2abcdef123456`）→ 填进 `config.js` 的 `cloudEnv`。

**2. 建数据库集合**

云开发控制台 → 数据库 → 新建集合，名字必须是 **`remind_users`**，
权限选「所有用户不可读写」（只有云函数能访问，客户端不需要直连）。

**3. 申请订阅消息模板**

[微信公众平台](https://mp.weixin.qq.com) → 功能 → 订阅消息 → 选用模板，
搜「上课」「课程提醒」类模板。记下两样东西：

- 模板 ID（形如 `Kq3Xk...`）
- 模板字段名（比如 `thing1` 课程名、`time2` 上课时间、`thing3` 上课地点）

字段名必须和模板完全一致，填错微信会返回 `47003`。

**4. 配云函数环境变量**

云开发控制台 → 云函数 → `remind` → 配置 → 环境变量：

| 变量名 | 值 |
|---|---|
| `REMIND_TEMPLATE_ID` | 模板 ID |
| `TEMPLATE_KEY_COURSE` | 课程名字段，默认 `thing1` |
| `TEMPLATE_KEY_TIME` | 时间字段，默认 `time2` |
| `TEMPLATE_KEY_ROOM` | 地点字段，默认 `thing3` |

**5. 部署云函数**

右键 `cloudfunctions/remind` → 上传并部署 → **云端安装依赖**
（本地没有 `node_modules`，选「所有文件」会上传失败）。

**6. 上传定时触发器**

右键 `cloudfunctions/remind` → 上传触发器。`config.json` 里配的是
`0 */5 * * * * *`，即每 5 分钟扫一次。

**7. 打开开关**

小程序 → 课表页右上角「提醒」→ 打开「上课提醒」开关 →
弹出微信授权（必须点允许）→ 课表会同步到云函数。

之后每 5 分钟，云函数会算一遍：谁下一节要上课、离上课还有几分钟是否落在提前时间内，
是就发一条订阅消息。

### 关于「只能收一条」

微信的**一次性订阅**规定：用户点一次授权，小程序只能发一条消息。
所以代码里用 `quota` 计数，发一条扣一次。

想多收几天，目前只能每天手动关掉再打开一次开关。
如果你想一次授权长期有效，需要申请**长期订阅**类目（教育/公共服务方向），
拿到之后把云函数里这行改掉即可：

```js
// handleSync 里，把 quotaDelta 逻辑换成固定额度
patch.quota = 9999;
```

## 已知边界

- **数据只在本机**：课表和待办存在微信本地缓存，换手机或清缓存会丢。
  云端只存了发提醒所需的一份课表副本。
- **不做冲突检测**：同一时段加两门课不会提示。
- **定时精度**：触发器每 5 分钟一次，所以提醒时间误差在 ±5 分钟内；
  提前时间设成 5 分钟以下可能刚好错过一轮。
- **半夜不发**：云函数在 23:00–06:00 之间直接跳过。
